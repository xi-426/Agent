# 本项目虚构示例公司：信息安全与数据分级规范

> 虚构声明：本文档仅作为企业知识库智能 Agent 项目的测试资料。公司名称、制度编号、组织角色和业务场景均为虚构，不代表或影射任何现实企业，也不构成法律或管理建议。

## 1. 目的

本规范用于保护客户数据、公司知识产权、账号凭证和业务连续性。所有数据处理遵循合法、必要、最小、可追溯原则。人员是否可以看到某项数据，由岗位职责和已批准用途决定，而不是由技术上是否能够访问决定。

## 2. 数据分级

| 级别 | 定义与示例 | 基本要求 |
|---|---|---|
| L1 公开 | 官网内容、已发布白皮书、公开招聘信息 | 可公开传播，但发布前须确认内容和品牌一致性 |
| L2 内部 | 普通流程、内部培训、非敏感会议纪要 | 仅限授权人员和受控协作工具，不得公开分享 |
| L3 机密 | 客户合同、未发布产品计划、源代码、财务数据 | 最小权限、传输加密、禁止使用个人网盘和私人邮箱 |
| L4 严格机密 | API 密钥、生产凭证、客户原始数据、身份证明和高权限审计记录 | 使用专用密钥或权限系统，禁止复制到聊天、文档和普通工单，访问必须审计 |

无法确定级别时，按更高一级处理，并向数据负责人确认。

## 3. 账号与访问控制

1. 每人使用独立账号，禁止共享个人账号、验证码和多因素认证设备。
2. 生产环境、代码仓库、云平台和管理后台必须启用多因素认证。
3. 权限按最小必要原则授予；临时高权限必须设置到期时间。
4. 每月复查管理员账号，每季度复查全部关键系统权限。
5. 员工离职或合作终止后 4 小时内停用关键系统账号，24 小时内完成设备、令牌和数据交接。
6. 连续 90 天未使用的账号应自动禁用或进入人工复核。

## 4. 密钥和密码

- API Key、数据库密码、私钥和令牌不得写入源代码、Git 提交、普通文档、截图或聊天记录。
- 本地开发使用环境变量或受控密钥文件，生产环境使用专用秘密管理系统。
- 发现密钥泄露时不得仅删除泄露内容，必须立即吊销旧密钥、生成新密钥并检查访问日志。
- 密码不得在多个工作系统重复使用；禁止通过明文消息发送初始密码。

## 5. 客户数据处理

- 客户数据只能用于合同和已批准测试范围，不得用于员工个人实验或未经批准的模型训练。
- 开发和演示优先使用脱敏或合成数据。确需使用真实数据时，必须记录用途、范围、保存位置和删除日期。
- 数据导出应限制字段、时间范围和接收人，并保留操作记录。
- 客户数据不得进入未经安全评估的第三方 AI、文件转换、翻译或分析服务。
- 终止合作后按合同和适用要求删除或返还数据，并保留删除确认记录。

## 6. 开发安全

1. 合并到主分支的代码至少经过一名非作者评审。
2. 身份认证、权限、文件上传、反序列化和外部命令调用属于重点审查区域。
3. 文件上传必须校验大小、扩展名和真实内容类型；磁盘文件名不得直接使用用户输入。
4. 日志不得记录密码、令牌、完整身份证号、银行卡号和客户文档正文。
5. 依赖出现高危漏洞时，24 小时内完成影响判断；可被利用的高危漏洞原则上 72 小时内完成缓解或修复。
6. 对模型输出执行数据库写入、删除或外部通知前，必须进行权限校验、参数校验和必要的人类确认。

## 7. 终端与办公设备

- 公司设备必须启用磁盘加密、自动锁屏、防病毒或终端防护以及自动安全更新。
- 不得在公共电脑处理 L3 或 L4 数据。
- 设备丢失、被盗或疑似被控制时，应在发现后 30 分钟内通知安全负责人。
- 移动存储设备默认禁止使用；业务确需使用时须加密并登记负责人和归还时间。

## 8. 安全事件分级与时限

| 级别 | 示例 | 首次上报 | 响应要求 |
|---|---|---|---|
| P0 灾难 | 大规模客户数据泄露、生产核心系统完全失控 | 立即，最迟 15 分钟 | 启动公司级应急响应，持续更新管理层 |
| P1 严重 | 单一客户敏感数据暴露、管理员凭证泄露 | 30 分钟内 | 立即隔离、保全证据并通知安全负责人 |
| P2 重大 | 可被利用的高危漏洞、受限范围异常访问 | 2 小时内 | 当日完成影响评估和缓解计划 |
| P3 一般 | 未造成数据暴露的策略违规或低风险漏洞 | 1 个工作日内 | 进入安全工单并按计划修复 |

任何人不得因尚未确认全部事实而延迟上报。首次上报可以是不完整信息，但必须标明已知事实、未知事项和下一次更新时间。

## 9. 供应商管理

供应商接触 L3 或 L4 数据前，业务负责人必须确认其数据用途、存储位置、访问人员、分包情况、事件通知机制和数据删除方式。供应商权限应独立、可撤销并有期限，不得复用内部员工账号。

## 10. 违规与例外

因紧急业务需要暂时无法满足本规范时，必须提交安全例外，写明风险、补偿控制、负责人和到期日期。未经批准的绕过行为不属于例外。故意泄露凭证、隐瞒事件或规避审计将按照严重违规处理。
