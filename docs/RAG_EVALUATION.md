# RAG 校准与评测

## 1. 当前检索方案

当前版本采用可解释的稠密向量检索：bge-m3 生成向量，pgvector 按余弦距离升序返回 Top-K，再通过最大距离门控决定是否进入生成阶段。

```text
问题
  -> bge-m3 生成 1024 维问题向量
  -> pgvector 在当前知识库的 READY 文档中按余弦距离升序检索
  -> 取 Top-K
  -> 过滤 distance > maxDistance 的切片
  -> 没有合格切片：直接资料不足拒答，不调用聊天模型
  -> 有合格切片：构造带 [资料N] 的上下文并调用 DeepSeek
  -> 返回 answer + sources
```

## 2. 真实数据与划分

- 语料：12 份真实学校资料。
- 当前切片：44 个，每个切片对应一条 1024 维向量。
- 标注问题：48 条。
- 有答案问题：36 条，每条标注真实 document ID 和 chunk ID。
- 无答案问题：12 条，不标注来源。
- 校准集：32 条，其中 24 条有答案、8 条无答案。
- 隔离测试集：16 条，其中 12 条有答案、4 条无答案。

校准集用于选择参数；测试集只用于最终报告，避免在测试结果上反复调参。

## 3. 切片参数

先根据真实语料长度构造 17 组切片方案，并在每组方案上重新切片、向量化和比较原始检索指标。最终使用：

- `chunk-size = 800` 字符；
- `chunk-overlap = 120` 字符。

跨切片方案使用文档级标签，因为重新切片后 chunk ID 会改变；固定 800/120 后，再使用精确 chunk ID 校准检索参数。这是小规模本地实验结果，不是行业固定值。

## 4. Top-K 怎样确定

校准接口最多取 20 条结果，记录 K=1..20 的原始向量检索曲线：

| K | 校准集原始 Hit@K |
|---:|---:|
| 1 | 83.33% |
| 2～7 | 95.83% |
| 8～20 | 100% |

K=8 是曲线第一次达到最高值的位置；继续增大 K 没有提高 Hit，却会增加 Prompt 字符和噪声，所以选择最小的平台起点：`topK=8`。这里的 20 只是校准接口的计算保护上限，不是算法结论。

## 5. 距离阈值怎样确定

阈值只使用校准集：

1. 对每道题记录最接近切片的真实余弦距离。
2. 枚举实际观测到的距离边界。
3. 优先要求 8 条无答案校准题误接受数为 0。
4. 在零误接受约束下，让尽可能多的有答案问题通过。
5. 取最后一个接受边界与下一个拒绝边界之间的中点。

得到 `maxDistance=0.3495513922998467`，展示时约写 `0.3496`。它是余弦距离上限，不是“34.96% 相似度”；距离越小通常越相似。

## 6. 独立测试结果

| 指标 | 结果 | 含义 |
|---|---:|---|
| 有答案题 Hit@8 | 11/12 = 91.67% | 人工相关切片进入门控后的 Top 8 |
| MRR@8 | 0.8611 | 第一个相关切片总体排位 |
| nDCG@8 | 0.8750 | 相关切片出现与位置的综合质量 |
| 上下文精度@8 | 0.4452 | 返回上下文中人工相关切片占比 |
| 门控决策准确率 | 15/16 = 93.75% | 正确判断回答或拒答 |
| 无答案误接受 | 0/4 | 4 条无答案测试题均被拒绝 |
| 有答案误拒绝 | 1/12 | 1 条有答案题未通过门控 |

Hit@8 和门控准确率评价不同问题，所以可以同时出现 91.67% 与 93.75%。这些指标都不是大模型生成答案准确率。

## 7. 为什么评测不批量调用 DeepSeek

本次固定评测只验证检索和门控，避免生成随机性、费用和模型版本变化干扰参数比较。答案忠实度、引用一致性和完整性属于生成层评测，应使用另一套标注与评分标准。

## 8. 适用边界

- 48 条仍是小规模本地评测，只说明当前12份资料。
- 当语料主题、切片方式、Embedding 模型或问题分布明显变化时，应扩充标注并重新校准。
- 当前只有44条向量，不能声称 HNSW 已获得可量化性能提升。
- 如果未来加入 BM25+RRF 或 Cross-Encoder，应与当前向量基线做同一测试集上的质量、延迟和资源对比。

原始标注与结果位于本地 `local-evaluation-data/`。每个参数的分类与面试口径见 [参数证据表](PARAMETER_EVIDENCE.md)。
