# RAG 固定评测集

## 目的

本评测集只针对 `sample-documents/` 下 5 份原创虚构企业规范。每次修改 Embedding 模型、切片策略、Top-K、距离阈值、Prompt 或 Rerank 后，都应重复运行同一批问题并比较结果。

## 判定指标

- `Hit@3`：期望文档是否出现在前三个召回结果中。
- 拒答准确率：应拒答的问题是否返回“知识库中没有足够资料回答该问题”。
- 引用准确率：答案引用的资料是否直接支持对应结论。
- 答案忠实度：回答是否只使用资料中的事实，没有自行补充数字、期限、责任人或规则。
